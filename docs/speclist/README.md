# Specs

Saída do Spec Kit: uma pasta por funcionalidade, com `spec.md`, `plan.md` e `tasks.md`.

**Não confundir com duas pastas vizinhas.** As três respondem perguntas diferentes:

| Pasta | Responde | Organiza-se por | Dura |
|---|---|---|---|
| `speclist/` | o que vamos construir agora, em que passos | funcionalidade | até o trabalho terminar |
| `comportamento/` | o que cada tela faz, e onde ela está no Figma | tela ou fluxo | permanente |
| `spec/` | quanto vale cada token visual | coleção de variáveis | permanente |

Uma spec **consome** o contrato de comportamento; nunca o substitui. O contrato é verdade
sobre o produto, a spec é plano de trabalho.
