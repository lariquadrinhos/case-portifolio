# Spec visual

Valores visuais descendo das variáveis do Figma — cor, tipografia, espaço, forma.

**Ainda vazio.** Como os tokens entram no código é a pergunta P07, agendada para a Fase 1.

Fonte: <https://www.figma.com/design/hwClE9Xpm51OW4vPsCCn8J/?node-id=34-2>, página
*Sistema visual*. Três coleções: Cor (modos Claro e Escuro), Tipografia (Desktop e Tela
pequena), Espaço e forma.

**Nenhum valor visual é digitado à mão no código sem vir de uma dessas coleções.** Valor
necessário que não existe lá é lacuna — e lacuna vira pergunta, não suposição.
